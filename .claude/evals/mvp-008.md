# MVP-008 — capability and regression definition

Baseline: local 0e857b92 / deployed b4f8baa4; 757 CI checks. Define before implementation.

## Capability gates

- A: versioned synthetic everyday/affection/support/recall/task fixtures; deterministic safety/pacing checks are separate from human tone review. Report every raw outcome, repair/fallback, latency and provider usage; mock runs do not establish live naturalness. A live run requires an explicit turn/call ceiling and never retries the whole corpus automatically.
- B: account-scoped persistent nickname, length, affection, questions, advice and timezone. Strict enums/limits and optimistic version. Current explicit request overrides preference. Nickname is quoted data, never instructions; reserved affection prevents default affectionate names; detailed/help/safety content is not truncated. Settings remain after restart and never cross users.
- C: recent life events remain separate from enduring facts. Literal user statements support planned/ongoing/completed/cancelled; questions, quotations and hypotheses are not assertions. Relative dates use source receipt time and captured timezone; expiry does not imply completion/cancellation. Multiple matching events make short updates ambiguous. Old jobs cannot overwrite newer status; initial migration does not backfill old messages. No automatic outreach tasks.
- D: standalone Weixin commands list/remember/correct/disable, then explicit short-code confirmation within ten minutes. Owner-scoped, durable command idempotency, expected-version checks, no CORE changes or permanent deletion. Disabled slots stay muted against queued continuity jobs; only a new explicit confirmed remember unmutes. Quoted/compound commands and ordinary “记住” text do not mutate state. Command bursts are not merged into normal turns; no model calls for management commands.

## Regression gates

Original conversation replay; identity/relationship invariants; validation before display projection; one repair maximum; ordinary detailed help and emotional support preserved; RLS and pool owner reset; 007 grouping/cancellation/uncertain-send semantics; outreach default remains unchanged and owner-controlled; no ports/resource/proxy changes.

## Grading

Vitest/code graders + fixed synthetic rule checks. Human review required for tone and false positives. No model-as-judge call, pass@k score or reliability claim without matching independent trials. Local Docker skips are explicit; CI runs real PostgreSQL. Record changes, counts, failures and source tree in release report. Use the product-eval workflow; do not use optional gate/capsule utilities as containment or promotion evidence.
