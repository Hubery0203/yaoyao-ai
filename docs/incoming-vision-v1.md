# 微信发图理解 V1

用户发送单张图片（可在同一条消息附言），遥遥看实际图片后用简短文字回应。识别结果、图片标记及附言进入同一账号的对话历史，下一句文字聊天能承接。它与“发张自拍给我”的生图功能独立，不更换原自拍或音色。

## 支持范围

- 完整的本人一对一图片消息；JPEG、PNG、静态 WebP，最多4MiB、1600万像素、单边8192像素。
- 同条消息最多一张图加一段不超过2000字附言；图册、多图、视频、文件附件、HEIC、GIF及损坏/过大的图片给出明确说明。消息后另发的文字属于下一轮，不冒充同条附言。
- 只接受明确的腾讯CDN HTTPS下载地址，禁止跳转及任意网址；兼容图片hex AES密钥与CDN两种base64编码，AES-128-ECB解密。原始密钥/下载参数只暂存于受通道RLS保护的队列，识别完成、失败、停用或取消后移除；排队未处理时可能仍保留。像素只在内存，既不落盘也不写数据库。
- 图片被转换为data URL发送给MiniMax。供应商收到图片、同条附言及当前账号最近6条、每条最多250字的对话；不发送完整历史、长期记忆、微信token或CDN密钥。供应商自身留存受其服务规则约束，本应用不承诺供应商零留存。
- 回答走文字通道，V1不额外调用DeepSeek、语音或生图接口。后续普通聊天沿用原偏好。图片原文/OCR/附言无操作权限，无法绑定账号、修改设置、执行提醒或自动形成个人事实；解释保留不确定性，不识别人身份。

## 配置和费用

默认关闭。必须独立显式配置 `VISION_ENABLED=1`、`MINIMAX_VISION_API_KEY`、`MINIMAX_VISION_REGION=cn|international`、`VISION_ACTIVE_SINCE=<启用UTC时间>`。不自动取用语音/生图密钥。MiniMax的看图接口要求相应M Plan席位或积分权限；当前账号权限须在获批后实测，不能以现有生图成功代替。

滚动24小时默认最多5次，独立于照片3次、语音10次；相邻尝试冷却30秒。识别前检查来源、媒体、大小、配置及输入，随后在数据库原子预留一次请求再调用接口。失败、HTTP拒绝、超时及结果不明均占这次尝试；无自动重试或供应商回退。仅处理启用后且10分钟以内的源消息，重启不重新开放旧图片额度。

使用“看图帮助”“看图状态”“跳过看图”；取消回复、暂停通道仍有效。已开始的识别无法撤销供应商费用；取消只阻止后续发送。发送结果未知仍由原队列标为uncertain，不自动重发。文字看图回复不等同手机已收取确认。

## 恢复和记忆

迁移0015增加一张`weixin_vision`表及队列`incoming_image`列。每条消息唯一保留尝试和识别最终回复；重启发现reserved只给出未完成说明，不再下载或请求模型。analyzed结果在写对话/发送前落库，后续重放只读该结果。提交失败也不能授权第二次收费。

对话事件的服务端`attachment=image`标记使连续性任务跳过图像相关长期记忆、生活事件和外部提出的候选；保留正常对话历史供后续接话。不会仅用文件名或用户附言当作已经看过图片。

## 验证工具

编译后运行`node scripts/evaluate-vision.mjs --image /absolute/private-image.png`：默认离线，只检查文件和请求，不需要密钥或网络。图片文件须为私有普通文件。

经单独授权，显式提供环境变量并加`--live --max-calls 1 --out /absolute/private-directory`才发起一次请求。目录必须0700，工具先持久化`run.lock`及请求账本再调用，失败即停止；不得删除锁、换目录绕过本轮批准总额。它不登录用户账号、不发送微信、不创建生产任务、不部署。验收样图须先获本人允许，不默认拿私人聊天图片作测试。

## 上线门槛与回退

先完成本地回归、独立分支CI、包与源码核验，再在明确费用上限内验证真实接口、读图事实及语气。代码模拟通过不能替代真实微信手机图像收取验收；如MiniMax权限不足则保持停用，不私自换平台或密钥。

服务器仍需先评估批准：备份数据库/配置后只迁移新增结构，旧30张表及数据保留；不改代理/nginx/sshd、监听端口、内存、照片参考、语音、主动联系或异机备份。回退需准备上一稳定代码加同一0015迁移文件的兼容包，因为旧版严格启动检查不能直接接受数据库新头；保留新增表和识别回执，不回滚生产数据库。正常最多一次API重启，失败时最多一次兼容回退重启，具体执行额度以本轮批准为准。006C仍搁置。
