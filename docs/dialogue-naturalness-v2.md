# 对话自然度第二轮

## 问题与范围

已有合成样本出现普通分享被解释成普遍道理，以及回答后追加“我听着呢，你慢慢说”。本轮以小分享为范围，用简短的正向接话示意补充表达指导；示意不是固定回复或可直接发送的模板。保留详细求助、必要支持、事实边界与如实身份回答。

- 小分享收到具体回应后收住，不附监听式邀请或强行追问。
- 新校验仅拒绝普通分享中附在完整句子后的两类已观察尾句，沿用一次修复；不静默删掉原始候选中的问题。
- 单独的陪伴回应、引用、明确倾听请求、安静请求、求助与安慰场景保留支持。
- “今天……如何排查 / 解释一下 / 给我列……”不再套用日常分享提示。
- 识别“今天/今晚想安静一会”。
- 接话提示仍通过已有小于 300 字的开头提示预算回归；不新增模型调用层。

## 本地验证

`npm run build`、`npm run lint`、`npm run boundaries`、`git diff --check` 通过。
`npx vitest run tests/unit core tests/contract`：888 项通过，新增 18 项。

8 个固定模拟场景、9 次模拟 generate、0 规则失败：小分享、无问题分享、文字提到照片、亲昵、安静、详细求助、技术请求、直接身份问题；包含请求回放与一次修复检查。

模拟文本由 fixture 提供，不能证明真实模型语气改善。未使用真实用户聊天；未进行付费模型测试、上传 GitHub 或服务器写入。

## 后续真实审阅

使用 `tests/fixtures/naturalness-v2.json`，在另行获得额度授权后按次计数真实检查。人工同时查看原始候选与最终输出，记录修复占比；不能用模拟结果替代自然度审阅。不同意候选语气时停止发布，不自行扩额度。

不应虚构用户现场、看过未收到的照片、线下生活或事实；详细回答应保持充分，安静不被追问，亲昵不附解释，身份提问如实回答。保持既有语音路由、每日额度、图片参考源及不重复投递机制。
